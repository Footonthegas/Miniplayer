This policy explains what information the extension processes, why it is used, and how Premium subscription verification works.

1. Who operates the extension

Mini Player and PiP for Netflix is operated by [PUBLISHER LEGAL NAME OR BUSINESS NAME] (“we”, “us”). Privacy questions can be sent to [SUPPORT EMAIL].

2. Information processed by the extension

Extension installation identifier and activation token. When the extension needs to check a Premium entitlement or create checkout, it creates a random installation ID and a random activation token. These are stored in Chrome extension local storage so the installation can be associated with its subscription. The extension sends them to our API over HTTPS. The server stores a SHA-256 hash of the token rather than the raw token.

Playback and subtitle content. To display a floating player, the extension interacts with the video element and reads currently displayed subtitle text on the Netflix page. This processing happens in the browser to provide the feature. The extension's Premium API is not intended to receive or store Netflix video, subtitle text, viewing history, Netflix credentials, or Netflix account details.

Subscription and entitlement metadata. When checkout is started, the server creates a Razorpay subscription and stores the subscription ID, status, current period end where supplied, checkout URL, installation ID, and timestamps. The installation ID is included in the subscription's Razorpay notes to match a verified webhook to the correct extension installation.

Request/security metadata. The API host and server infrastructure may process technical request data, such as IP address, timestamps, and request logs, to deliver the service, apply rate limits, troubleshoot errors, and protect the endpoint. Exact infrastructure log retention is controlled partly by the hosting provider.

3. Payments

Payments and recurring subscription authorisation are handled by Razorpay on its hosted payment pages. We do not intentionally collect or store full card numbers, CVV values, bank credentials, UPI PINs, or other payment authentication secrets in the extension or our entitlement database. Razorpay handles payment information under its own policies and terms. We receive subscription-related identifiers and status through Razorpay's API and webhook notifications.

4. How information is used

  • To create a subscription checkout and associate it with the extension installation that initiated it.
  • To verify whether Premium is active and enable paid extension features only when the server confirms an entitlement.
  • To protect the service from abuse, enforce request limits, diagnose failures, and respond to support requests.
  • To maintain payment/subscription records and comply with applicable legal obligations.

5. Service providers and sharing

Information is shared only as needed with service providers that support the feature: Razorpay for subscription processing and related events, Supabase for entitlement database storage, and the selected hosting provider for the API and public policy pages. These providers process information according to their own terms and applicable agreements. We do not sell personal information or use Netflix subtitle content for advertising.

6. Storage and retention

The installation ID and activation token remain in Chrome local storage until extension data is cleared or the extension is removed. The server retains subscription/entitlement metadata while needed to operate and secure Premium access and to address payment, support, or legal requirements. To ask for deletion or raise a privacy concern, contact [SUPPORT EMAIL]. Some records may need to be retained when required by law or for legitimate transaction disputes.

7. Security

The extension is designed to use HTTPS for requests to the Premium API. The backend stores a hash of the activation token and keeps Razorpay credentials and the Supabase service-role key on the server, not in extension code. No internet-connected system can be guaranteed completely secure; report suspected vulnerabilities to [SUPPORT EMAIL].

8. Your choices

You can stop using the extension or remove it in Chrome. Removing the extension clears locally stored extension data, but does not by itself delete subscription records or cancel a Razorpay subscription. Subscription cancellation must be completed using the cancellation method explained at checkout or in the Terms page. Contact us for privacy requests.

9. Children and third-party services

The extension is a productivity utility, not a service designed specifically for children. Netflix and Razorpay are separate services governed by their own terms and privacy notices. We do not control their data practices.

10. Changes to this policy

We may update this policy when the product or its data practices change. The “Last updated” date above will be revised when changes are published. Material changes will be disclosed as required by applicable law and platform rules.
